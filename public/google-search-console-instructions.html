Google Search Console Setup & Verification

Complete operational guide for connecting LankaForex.com to Google Search Console, Bing Webmaster Tools, and AI Answer Engines (Perplexity, ChatGPT, Claude).

1 Option A: Verify via Environment Variable (HTML Meta Tag)

LankaForex.com is pre-wired to read the Google site verification token directly from your environment variables.

1. Open Google Search Console → Add Property → Select URL prefix (e.g. https://lankaforex.com).

2. Choose HTML tag as the verification method. You will get a tag like:

<meta name="google-site-verification" content="ABCxyz1234567890_EXAMPLE_TOKEN" />

3. Copy only the content string (e.g. ABCxyz1234567890_EXAMPLE_TOKEN).

4. Add it to your .env.local or Vercel / hosting environment variables:

NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION="ABCxyz1234567890_EXAMPLE_TOKEN"

5. Redeploy your application and click Verify in Google Search Console.

2 Option B: Verify via DNS TXT Record (Recommended)

This is the most robust method as it verifies the entire domain lankaforex.com including www and any future subdomains.

  • In Google Search Console, select Domain property type: lankaforex.com.
  • Copy the provided TXT record value: google-site-verification=...
  • Sign in to your domain registrar (e.g., Cloudflare, Namecheap, GoDaddy, Hostinger).
  • Add a DNS Record:
    • Type: TXT
    • Host / Name: @ (or lankaforex.com)
    • Value / Content: google-site-verification=...
    • TTL: Automatic / 300 seconds
  • Click Verify in Google Search Console.
